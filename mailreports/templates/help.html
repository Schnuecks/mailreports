{{ _("Worum geht es?") }}

{{ _("Jeder kann eine Mail verschicken, in der eine fremde Absenderadresse steht. Drei Einträge im DNS deiner Domain sorgen dafür, dass empfangende Server echte von gefälschten Mails unterscheiden können: SPF, DKIM und DMARC. Große Mailanbieter schicken dir täglich einen Bericht, was sie mit Mails in deinem Namen erlebt haben – diese App sammelt und erklärt sie.") }}

SPF

{{ _("Sender Policy Framework: eine Liste der Server, die für deine Domain Mails verschicken dürfen. Der Empfänger prüft, ob die IP des einliefernden Servers auf dieser Liste steht. Geprüft wird die Domain aus dem „Envelope-From“ (Return-Path), nicht die sichtbare Absenderadresse.") }}

{{ _("Schwäche: Wird eine Mail weitergeleitet, liefert sie ein fremder Server ein – SPF schlägt dann fehl, obwohl die Mail echt ist.") }}

DKIM

{{ _("DomainKeys Identified Mail: Dein Mailserver unterschreibt jede Mail kryptografisch. Den öffentlichen Schlüssel findet der Empfänger im DNS unter ._domainkey.. Der Selektor ist nur ein Name für den Schlüssel, so können mehrere Schlüssel parallel existieren – etwa einer für den eigenen Server und einer für einen Newsletter-Dienst.") }}

{{ _("Die Signatur übersteht Weiterleitungen, solange die Mail unterwegs nicht verändert wird.") }}

DMARC

{{ _("DMARC verbindet beides mit der sichtbaren Absenderadresse („Header-From“). Eine Mail besteht DMARC, wenn SPF oder DKIM bestanden hat und die geprüfte Domain zur Absenderadresse passt. Außerdem legt DMARC fest, was mit durchgefallenen Mails passieren soll:") }}

  • p=none – {{ _("nur beobachten und Berichte schicken") }}
  • p=quarantine – {{ _("in den Spam-Ordner verschieben") }}
  • p=reject – {{ _("gar nicht erst annehmen") }}

{{ _("sp= gilt für Subdomains, pct= für den Anteil der Mails, auf den die Richtlinie angewandt wird.") }}

{{ _("Ausrichtung (Alignment)") }}

{{ _("„Passen“ heißt bei DMARC: Die von SPF oder DKIM geprüfte Domain muss zur Absenderadresse gehören. Bei entspannter Ausrichtung (adkim=r, aspf=r) reicht dieselbe Hauptdomain, mail.example.org passt also zu example.org. Bei strenger Ausrichtung (adkim=s, aspf=s) müssen die Domains exakt gleich sein.") }}

{{ _("Darum kann eine Mail SPF „bestehen“ und trotzdem DMARC verfehlen: Ein Dienst prüft SPF für seine eigene Domain, nicht für deine.") }}

{{ _("Ergebnis beim Empfänger") }}

{{ _("„Zugestellt“, „Quarantäne“ und „Abgewiesen“ zeigen, was der Empfänger tatsächlich getan hat. Das kann von deiner Richtlinie abweichen, etwa wenn er eine Weiterleitung als vertrauenswürdig erkennt – das steht dann als Ausnahme im Bericht.") }}
