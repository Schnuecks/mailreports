{{ _("Überblick") }}

{{ _("Die Absenderadresse einer E-Mail lässt sich beliebig fälschen. Drei Einträge im DNS einer Domain ermöglichen empfangenden Servern, legitime von gefälschten E-Mails zu unterscheiden: SPF, DKIM und DMARC. Große Mailanbieter senden täglich Berichte darüber, welche E-Mails im Namen der Domain bei ihnen eingegangen sind. Diese Anwendung sammelt und erläutert diese Berichte.") }}

SPF

{{ _("Sender Policy Framework: eine Liste der Server, die im Namen einer Domain E-Mails versenden dürfen. Der empfangende Server prüft, ob die IP-Adresse des einliefernden Servers auf dieser Liste steht. Geprüft wird die Domain aus dem „Envelope-From“ (Return-Path), nicht die sichtbare Absenderadresse.") }}

{{ _("Einschränkung: Bei einer Weiterleitung liefert ein fremder Server die E-Mail ein. SPF schlägt dann fehl, obwohl die E-Mail legitim ist.") }}

DKIM

{{ _("DomainKeys Identified Mail: Der Mailserver signiert jede E-Mail kryptografisch. Den öffentlichen Schlüssel findet der empfangende Server im DNS unter ._domainkey.. Der Selektor benennt den Schlüssel; so können mehrere Schlüssel parallel bestehen, etwa für den eigenen Server und für einen Newsletter-Dienst.") }}

{{ _("Die Signatur bleibt bei Weiterleitungen gültig, solange die E-Mail unterwegs nicht verändert wird.") }}

DMARC

{{ _("DMARC verknüpft beide Verfahren mit der sichtbaren Absenderadresse („Header-From“). Eine E-Mail besteht DMARC, wenn SPF oder DKIM bestanden wurde und die geprüfte Domain zur Absenderadresse passt. Außerdem legt DMARC fest, wie mit E-Mails verfahren wird, die DMARC nicht bestehen:") }}

  • p=none – {{ _("nur überwachen und Berichte senden") }}
  • p=quarantine – {{ _("in Quarantäne (Spam-Ordner) verschieben") }}
  • p=reject – {{ _("bei der Zustellung abweisen") }}

{{ _("sp= gilt für Subdomains, pct= für den Anteil der E-Mails, auf den die Richtlinie angewandt wird.") }}

{{ _("Ausrichtung (Alignment)") }}

{{ _("Bei DMARC muss die von SPF oder DKIM geprüfte Domain zur Absenderadresse gehören. Bei entspannter Ausrichtung (adkim=r, aspf=r) genügt dieselbe Organisationsdomain; mail.example.org passt also zu example.org. Bei strenger Ausrichtung (adkim=s, aspf=s) müssen die Domains identisch sein.") }}

{{ _("Daher kann eine E-Mail SPF bestehen und DMARC dennoch verfehlen: Ein Dienst prüft SPF für seine eigene Domain, nicht für die Absenderdomain.") }}

{{ _("Ergebnis beim Empfänger") }}

{{ _("„Zugestellt“, „Quarantäne“ und „Abgewiesen“ geben an, wie der empfangende Server tatsächlich verfahren ist. Das kann von der veröffentlichten Richtlinie abweichen, etwa wenn er eine Weiterleitung als vertrauenswürdig einstuft; der Bericht nennt dann eine Ausnahme.") }}
